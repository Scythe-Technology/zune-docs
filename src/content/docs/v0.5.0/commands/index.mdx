# Application
---

The executable binary file itself.

### Usage

```bash
zune [command|flags] [...args]
```

### Flags
- `-e`, `--eval` - Evaluate the given string.
  - Example usage:
    ```bash
    zune -e "print('Hello, World!')"
    ```
- `-V`, `--version` - Display runtime version information.
  - Example output:
    ```
    zune: 0.1.0
    luau: 0.640
    ```
- `-h`, `--help` - Display help information.
