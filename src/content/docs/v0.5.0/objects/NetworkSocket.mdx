# NetworkSocket
---

A NetworkSocket is an object that represents a network socket. It provides methods to connect, send, and receive data over the network.

## Methods
### send
Sends data over the socket, and returns the number of bytes sent.
```luau tooltips
:send(data: string | buffer, offset: number?): number
```
<details open>
<summary>Parameters</summary>
- `data: string | buffer{:luau}` - The data to send over the socket.
- `offset: number?{:luau}` - The offset of the string/buffer.
  - default: `0`
</details>
<details>
<summary>Throws</summary>
- Network Error
- Memory Error
</details>

### sendMsg
Sends data over the socket, and returns the number of bytes sent.
```luau tooltips
:sendMsg(port: number, address: string, data: string | buffer, offset: number?): number
```
<details open>
<summary>Parameters</summary>
- `port: number{:luau}` - The port to send the data to.
- `address: string{:luau}` - The address to send the data to.
- `data: string | buffer{:luau}` - The data to send over the socket.
- `offset: number?{:luau}` - The offset of the string/buffer.
  - default: `0`
</details>
<details>
<summary>Throws</summary>
- Network Error
- Memory Error
</details>

### connect

<details open>
<summary>Parameters</summary>

</details>
<details>
<summary>Throws</summary>

</details>

### listen
Starts listening for incoming connections on the socket.
```luau tooltips
:listen(backlog: number?): ()
```
<details open>
<summary>Parameters</summary>
- `backlog: number?{:luau}` - The maximum number of connections the OS should queue before refusing new connections.
  - default: `128`
</details>
<details>
<summary>Throws</summary>
- Network Error
</details>
