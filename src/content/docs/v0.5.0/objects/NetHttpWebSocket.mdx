# NetHttpWebSocket
---

## Methods
### close
Closes the WebSocket connection.
```luau tooltips
:close(code: number?): ()
```
<details open>
<summary>Parameters</summary>
- `code: number?{:luau}` - The close code to send, if not provided, it will default to `1000` (Normal Closure).
</details>
<details>
<summary>Throws</summary>
- Memory Error
- WebSocket Error
</details>

### send
Sends a message to the connected WebSocket.
```luau tooltips
:send(message: string | buffer): ()
```
<details open>
<summary>Parameters</summary>
- `message: string | buffer{:luau}` - The message to send to the WebSocket.
</details>
<details>
<summary>Throws</summary>
- Memory Error
- WebSocket Error
</details>

### isConnected
Returns if the WebSocket is connected.
```luau tooltips
:isConnected(): boolean
```
