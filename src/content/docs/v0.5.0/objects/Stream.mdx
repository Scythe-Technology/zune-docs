# Stream
---

`Stream` is a simple class to write data or read data dynamically.

`IoReadable` and `IoWritable` are based on `Stream`.

Read functions are for when the stream is with reading enabled.
Write functions are for when the stream is with writing enabled.

## Methods
### read
```luau tooltips
:read(amount: number?, bytes: boolean?): string | buffer
```
<details open>
<summary>Parameters</summary>
- `amount: number?{:luau}` - The amount of bytes to read, if not provided, it will read until EOF or luau limit.
- `bytes: boolean?{:luau}` - If false, the function will return a `string` instead of a `buffer`.
</details>
<details>
<summary>Throws</summary>
- Reader Error
</details>
