## Methods
### digest
Returns the finalized hash value.

If the hash object was created with a key, this would close the object.
```luau tooltips
:digest(encoding: ("binary" | "hex" | "base64")?): string | buffer
```
<details open>
<summary>Parameters</summary>
- `bytes: boolean?{:luau}` - If false, the function will return a `string` instead of a `buffer`.
</details>
<details>
<summary>Throws</summary>
- Memory Error
</details>

```luau tooltips
:update(value: string | buffer): ()
```
<details open>
<summary>Parameters</summary>

</details>
<details>
<summary>Throws</summary>

### copy
Copies the current hash state.

If the hash object was created with a key, the object must still be opened.
```luau tooltips
:copy(): CryptoHash
```
<details>
<summary>Throws</summary>
- Crypto Error
- Memory Error
</details>
