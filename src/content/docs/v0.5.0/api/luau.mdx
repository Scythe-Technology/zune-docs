# Luau
`zune.luau`

---
import { Callout } from 'nextra/components'

A library to parse, compile and run luau code.

## Functions
### compile
Compiles `Luau` source code.
```luau tooltips
-- @hover: (31,45)[type CompileOptions = {
    debug_level: number?,
    optimization_level: number?,
    coverage_level: number?,
}]
compile(source: string, opts: CompileOptions?): string
```
<details open>
<summary>Parameters</summary>
- `source: string{:luau}` - The source code to compile.
- `opts: CompileOptions?{:luau}` - The options for the compilation.
  - `debug_level: number?{:luau}` - The debug level for the compilation.
  - `optimization_level: number?{:luau}` - The optimization level for the compilation.
  - `coverage_level: number?{:luau}` - The coverage level for the compilation.
</details>
<details>
<summary>Throws</summary>
- Luau Error
</details>

### load
Loads `Luau` bytecode into a function.
```luau tooltips
-- @hover: (30,41)[type LoadOptions = {
    env: {[any]: any}?,
    chunkName: string?,
    nativeCodeGen: boolean?,
}]
load(bytecode: string, opts: LoadOptions?): ((...any) -> ...any)
```
<Callout type="info"> `nativeCodeGen` will be disabled if the table from `env` field has a metatable. </Callout>
<Callout type="info"> If `env` is not provided, it will default to the global environment. </Callout>
<details open>
<summary>Parameters</summary>
- `bytecode: string{:luau}` - The bytecode to load.
- `opts: LoadOptions?{:luau}` - The options for the load.
  - `env: {[any]: any}?{:luau}` - The environment to use for the loaded function.
  - `chunkName: string?{:luau}` - The name of the chunk, used for debugging.
    - default: `(load)`
  - `nativeCodeGen: boolean?{:luau}` - Whether to enable native code generation.
</details>
<details>
<summary>Throws</summary>
- Luau Error
</details>
