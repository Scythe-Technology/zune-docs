# Network
`zune.net`

---

A library to do networking in luau. Provides functions to create sockets, start an HTTP server, make HTTP requests, and handle WebSockets.

#### serve
Starts a server on the specified port.
```luau tooltips
-- @hover: (13,25)[
type ServerRequest = {
    method: string,
    path: string,
    query: {[string]: string},

}

    status_code: number,
    headers: {[string]: string}?,
    body: string | buffer,
}

type ServerWebSocketHandlers = {
    upgrade: ((request: ServerRequest) -> boolean)?,

    open: ((websocket: NetHttpWebSocket) -> ())?,
-- @link: (27,43)[../objects/NetHttpWebSocket]
    message: ((websocket: NetHttpWebSocket, message: string) -> ())?,
-- @link: (25,41)[../objects/NetHttpWebSocket]
    close: ((websocket: NetHttpWebSocket, code: number) -> ())?,
}

type ServeOptions = {
    port: number,
    address: string?,
    reuse_address: boolean?,
    backlog: number?,
    max_body_size: number?,
    client_timeout: number?,
    max_connections: number?,
    request: (request: ServerRequest) -> string | buffer | ServerResponse,
    websocket: ServerWebSocketHandlers?,
}]
-- @link: (28,40)[../objects/NetHttpServer]
serve(opts: ServeOptions): NetHttpServer
```
<details open>
<summary>Parameters</summary>
- `opts: ServeOptions{:luau}` - The options for the server.
  - `port: number{:luau}` - The port to listen on.
  - `address: string?{:luau}` - The address to bind to.
    - default: `"127.0.0.1"{:luau}`
  - `reuse_address: boolean?{:luau}` - Whether to reuse the address.
    - default: `false{:luau}`
  - `backlog: number?{:luau}` - The maximum number of connections the
    - default: `128{:luau}`
  - `max_body_size: number?{:luau}` - The maximum size of the request body.
    - default: `4096{:luau}`
  - `client_timeout: number?{:luau}` - The timeout for the client.
    - default: `60{:luau}`
    - `0{:luau}` for no timeout
  - `max_connections: number?{:luau}` - The maximum number of connections.
    - default: `1024{:luau}`
    - `0{:luau}` for no limit
  - `request: (ServerRequest) -> string | buffer | ServerResponse{:luau}` - The function to call when a request is received.
    - If the function returns a `string{:luau}` or `buffer{:luau}`, the reuslt will be sent as the response body.
    - If the function returns a `ServerResponse`, the result will be used as the response.
  - `websocket: ServerWebSocketHandlers?{:luau}` - The handlers for WebSocket connections.
    - `upgrade: ((ServerRequest) -> boolean)?{:luau}` - The function to call when a WebSocket upgrade request is received.
      - If the function returns `true{:luau}`, the WebSocket connection will be accepted.
      - If the function returns `false{:luau}`, the WebSocket connection will be rejected.
    - `open: ((NetHttpWebSocket) -> ())?{:luau}` - The function to call when a WebSocket connection is opened.
    - `message: ((NetHttpWebSocket, string) -> ())?{:luau}` - The function to call when a message is received on a WebSocket connection.
    - `close: ((NetHttpWebSocket, number) -> ())?{:luau}` - The function to call when a WebSocket connection is closed.
</details>
<details>
<summary>Throws</summary>
- IO Error
- Network Error
</details>

<details open>
<summary>Parameters</summary>

  - `headers: {[string]: string}?{:luau}` - The headers to send with the request.
