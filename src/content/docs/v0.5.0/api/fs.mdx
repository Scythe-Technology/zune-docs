# File System
`zune.fs`

---
import { Callout, Tabs } from 'nextra/components'

A library that provides access to the file system.

## Functions
### createFile
Creates a file. If the file already exists, the function will throw an error only when `exclusive` is `true`.

```luau tooltips
-- @hover: (32,49)[type CreateFileOptions = {
    exclusive: boolean?,
}]
-- @link: (53,63)[../objects/FileHandle]
createFile(path: string, opts: CreateFileOptions?): FileHandle
```
<details open>
<summary>Parameters</summary>
- `path: string{:luau}` - The path to the file to open/create.
- `opts: CreateFileOptions?{:luau}` - The create options.
  - `exclusive: boolean?{:luau}` - If true, the function will fail if the file already exists.
    - default: `false{:luau}`
</details>
<details>
<summary>Throws</summary>
- IO Error
</details>

### openFile
Opens a file. If the file does not exists, the function will throw an error.
```luau tooltips

}]
-- @link: (49,59)[../objects/FileHandle]
openFile(path: string, opts: OpenFileOptions?): FileHandle
```
<details open>
<summary>Parameters</summary>
- `path: string{:luau}` - The path to the file to open.
- `opts: OpenFileOptions?{:luau}` - The create options.
  - `mode: string?{:luau}` - If provided, the file will be opened in the specified mode.
    - modes: `"r"{:luau}`, `"w"{:luau}`, `"rw"{:luau}`
    - default: `"rw"{:luau}`
</details>
<details>
<summary>Throws</summary>
- IO Error
</details>

#### join
Joins multiple paths into a single path with OS specific separator.
<Tabs items={['Unix', 'Windows']}>
  <Tabs.Tab>
  - (`lib`, `main.luau`) -> `lib/main.luau`
  - (`lib`, `lib/main.luau`) -> `lib/lib/main.luau`
  </Tabs.Tab>
  <Tabs.Tab>
  - (`lib`, `main.luau`) -> `lib\main.luau`
  - (`lib`, `lib\main.luau`) -> `lib\lib\main.luau`
  </Tabs.Tab>
</Tabs>

<details open>

</details>
