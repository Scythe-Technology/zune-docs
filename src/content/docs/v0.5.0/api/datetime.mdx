### parse
Parse a date string.
- Supports ISO8601 format, `YYYY-MM-DDTHH:MM:SSZ`.
- Supports RFC3339 format, `YYYY-MM-DDTHH:MM:SS+00:00`.
- Supports RFC2822 format, `Day, DD Mon YYYY HH:MM:SS GMT`.
```luau tooltips
-- @link: (22,30)[../objects/DateTime]
```
