# Cryptography
`zune.crypto`

---

A library to do cryptographic operations in luau. Provides functions for hashing, aead, tls, and secure random number generation.

<details open>
<summary>Parameters</summary>
- `password: string{:luau}` - The password to hash.
- `opts: PasswordOptions?{:luau}` - The options for password hashing.
  - `algorithm: ("argon2d" | "argon2i" | "argon2id" | "bcrypt")?{:luau}` - The algorithm to use.
    - default: `argon2id`
  - `time_cost: number?{:luau}` - The time cost to use (only for argon2).
    - default: `2`
  - `memory_cost: number?{:luau}` - The memory cost to use (only for argon2).
    - default: `65536`
  - `threads: number?{:luau}` - The number of threads to use (only for argon2).
    - default: `1`
  - `cost: number?{:luau}` - The cost to use (only for bcrypt).
    - default: `4`
</details>

### random
Cryptographically secure random number generator.

---
<h4 className="x:text-slate-900 x:dark:text-slate-100 x:mt-8 x:text-xl"><u>`FUNCTIONS`</u></h4>
#### nextNumber
Generates a random number (f64).

If no arguments are provided, the function will generate a number between 0 and 1.
```luau tooltips
random.nextNumber(min: number?, max: number?): number
```
<details open>
<summary>Parameters</summary>
- `min: number?{:luau}` - The minimum number.
  - If `max` is provided, `min` must also be provided.
- `max: number?{:luau}` - The maximum number.
  - If `min` is provided, `max` must also be provided.
</details>
<details>
<summary>Throws</summary>
- Range Error
</details>

#### nextInteger
Generates a random integer.

If no arguments are provided, the function will generate a number between the limits of a signed 32-bit integer.
```luau tooltips
random.nextInteger(min: number?, max: number?): number
```
<details open>
<summary>Parameters</summary>
- `min: number?{:luau}` - The minimum number.
  - If `max` is provided, `min` must also be provided.
- `max: number?{:luau}` - The maximum number.
  - If `min` is provided, `max` must also be provided.
</details>
<details>
<summary>Throws</summary>
- Range Error
</details>

#### nextBoolean
